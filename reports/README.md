# Reports

Generated narrative reports belong here. Generated plots belong in `figures/`
and are excluded from version control by default.

Reports:

- `data_quality.md` — initial source audit and EDA findings
- `baseline_results.md`
- `sensor_ablation_results.md`
- `robustness_results.md`
- `final_report.md`
- `model_card.md`

Each report should link to the exact experiment configuration and record the
code revision and data checksums used to produce it.
